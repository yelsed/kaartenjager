What we look for

  • 16 GB memory or more, in the listing itself. Hard requirement. Buying a second stick does not count; "8/16 GB" options count as the lowest.
  • Budget is a guideline, not a limit.
  • Processor: computing power per euro. No fixed floor. The ZenBook in the cluster (pve2) is only a reference point.

What the score means

The score is the PassMark CPU Mark: a fixed set of calculations (integer and floating point maths, prime numbers, sorting, encryption, compression, physics) run on all cores at once, averaged over everyone who ran the test.

  • It shows how much work all cores together get done. That is what compiling and running tests uses.
  • 15,300 against 5,940 means 2.6 times as much work in that test, not exactly 2.6 times faster builds: disk and memory speed also count.
  • It is an average. A badly cooled machine scores lower.

Trade-offs

  • Business 1-liter PCs (Lenovo Tiny, Dell Micro, HP Mini) are built to run day and night and are quiet, but with 32 GB they carry old Intel chips and score poorly per euro.
  • Consumer brands (Minisforum, GMKtec, Beelink, Geekom) give two to three times the computing power for the same money, but use laptop chips in a small box: louder under long load. Some have Realtek network cards that need extra work under Proxmox. Not checked per model yet.

What it will do

  • Becomes Proxmox node pve5. With five nodes, two may be down at once instead of one.
  • A virtual machine ci with two GitHub runners: two jobs at once, the rest waits in GitHub's own queue.
  • Only for private repositories. Public ones (kaartenjager, henk, goghmode) stay on GitHub's runners, so nobody can run code on the home network through a pull request.
  • One shared queue for all repositories needs a free GitHub organisation; with a personal account a runner belongs to one repository.
  • Self-hosted runners are free today; GitHub announced a fee for March 2026 and postponed it.
  • Later option: move the paperclip virtual machine to the new node and the runners to the ZenBook.
